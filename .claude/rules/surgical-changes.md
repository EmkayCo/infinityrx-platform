## Surgical Changes Rule
- Touch only what the task requires. No drive-by improvements.
- Don't "improve" adjacent code, comments, or formatting.
- Don't refactor things that aren't broken.
- Match existing style, even if you'd do it differently.
- If your changes create orphaned imports/variables, clean those up.
- If you notice unrelated dead code, mention it in tasks/lessons.md — don't delete it.
- Test: every changed line should trace directly to the task request.
