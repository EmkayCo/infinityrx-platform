# Golden Master Files

This directory stores golden master outputs for file generation tests.

Files stored here:
- `nacha_sample.txt` — golden NACHA file from known test data
- `835_sample.txt` — golden 835 remittance file from known test data
- `invoice_sample.txt` — golden invoice PDF text from known test data

When a golden master test fails, verify the change is intentional before updating.
